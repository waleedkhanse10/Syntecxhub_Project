Dark / Light Mode Toggle

Flip the switch in the navbar to change the theme. Your choice is saved in localStorage, and if nothing is saved the page follows your system preference. Colors come entirely from CSS variables — no hardcoded colors in JavaScript.

Why CSS variables?

Every color on this page lives in a CSS custom property. Switching themes just swaps the value of data-theme on the <html> element, and the browser re-resolves every variable instantly — with a smooth 0.3s transition on background, text and borders.
