# Syntecxhub_Landing_Page

A responsive landing page for a fictional AI coding tool ("CodePilot"), built with HTML and CSS only.
Project 2 of the Syntecxhub Frontend Development Internship (Week 1).

## Features

- Hero section with call-to-action buttons
- Features section and a call-to-action banner
- Responsive navbar with smooth scrolling
- Flexbox and Grid layouts
- Hover animations on buttons and links

## Tech Stack

HTML5, CSS3 (Flexbox, Grid, media queries)

## Run Locally

1. Clone the repository:
```bash
   git clone https://github.com/waleedkhanse10/Syntecxhub_Project.git
```
2. Go into the project folder:
```bash
   cd Syntecxhub_Project/Syntecxhub_Landing_Page
```
3. Open `index.html` in your browser (or use Live Server in VS Code).

## Note

CodePilot is a made-up product used for practice. The names, numbers and links on the page are placeholders.
