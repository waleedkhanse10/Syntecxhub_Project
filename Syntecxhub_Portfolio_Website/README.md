# Syntecxhub_Portfolio_Website

A responsive single-page portfolio website built with HTML and CSS only.
Project 1 of the Syntecxhub Frontend Development Internship (Week 1).

## Features

- Sections: About, Skills, Projects, Contact
- Responsive design for mobile and desktop
- Hover effects and transitions
- Smooth scrolling navbar

## Tech Stack

HTML5, CSS3 (Flexbox, Grid, media queries)

## Run Locally

1. Clone the repository:
```bash
   git clone https://github.com/waleedkhanse10/Syntecxhub_Project.git
```
2. Go into the project folder:
```bash
   cd Syntecxhub_Project/Syntecxhub_Portfolio_Website
```
3. Open `index.html` in your browser (or use Live Server in VS Code).
